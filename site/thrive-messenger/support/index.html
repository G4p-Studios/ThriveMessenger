Thrive Messenger Support

For help with the TappedIn Thrive Messenger client or the default im.tappedin.fm service, use the established Devine Creations support channels:

  • Contact form
  • Open a support ticket
  • Client area

Include the app version, device and operating-system version, selected server hostname, the action that failed, and any accessible error wording. Do not send passwords, private keys, passcodes, or full authentication tokens.

For an independent self-hosted server, contact its operator. For the original open-source code, see G4p Studios' Thrive Messenger project.
